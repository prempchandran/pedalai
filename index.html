🔑 How to get your free API key
  1. 1
    Go to console.anthropic.com — sign up free, no credit card needed to start.
  2. 2
    In the left sidebar click API Keys → + Create Key. Give it any name (e.g. PedalAI).
  3. 3
    Copy the key shown — it starts with sk-ant-. Save it somewhere safe — Anthropic won't show it again.
  4. 4
    Paste it in the box below and hit Save. It's saved only in your browser — never sent to any server.
  5. 5
    Add a small credit ($5 is plenty for hundreds of pedal lookups) at console.anthropic.com → Billing.
💡 Cost: Each custom pedal lookup costs <$0.01. Prebuilt pedals and all audio features are completely free — no key required.
🔒 Privacy: Your key is stored in your browser's localStorage only. It never leaves your device except to call Anthropic's API directly.
